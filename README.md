# 안녕하세요, 보안 관점으로 시스템을 분석하는 개발자입니다.

백엔드 개발 경험을 바탕으로 시스템의 동작 원리를 이해하고, 인증 구조와 데이터 처리 과정에서 발생할 수 있는 보안 문제를 분석하고 개선하는 데 관심이 있습니다.

- **Backend:** Java, Spring Boot, Kotlin, MySQL
- **Security:** 웹 취약점 분석 실습, JWT 인증 구조 개선, 결제 데이터 무결성 및 동시성 검증
- **Project:** Fundit — 게이트웨이 기반 JWT 검증 구조 개선 및 사용자 식별 정보 신뢰 문제 해결
- **Activities:** PortSwigger Web Security Academy, Dreamhack, Suninatas 문제 풀이

## 🔐 Security & Backend Projects

### [Fundit — 인증 구조 개선](https://github.com/semolu99/Fundit-backend)
- 클라이언트가 전달하는 사용자 식별 정보를 신뢰할 때 발생할 수 있는 접근 통제 문제를 발견했습니다.
- API Gateway에서 JWT 서명을 검증하고, 검증된 사용자 ID를 전달하도록 인증 구조를 개선했습니다.

### [결제 시스템 — 데이터 무결성 및 동시성 검증](https://github.com/semolu99/GMO-server)
- 클라이언트 입력값 변조와 중복 결제 가능성을 고려해 서버 측 검증 구조를 설계했습니다.
- 데이터베이스 제약 조건과 비관적 락을 적용하고, k6를 활용해 동시 요청 상황을 검증했습니다.
